# Agent 与机器人论文阅读清单

## 通用判断

每篇论文先回答：

1. 研究对象是纯软件 Agent、交互环境 Agent、机器人还是跨形态系统？
2. 论文声称的新能力是什么：表示、规划、记忆、工具、控制、数据、评测还是系统集成？
3. 结论来自仿真、沙盒、用户研究还是真实机器人？
4. 评测是否与部署条件一致？
5. 主要收益相对于什么基线，训练/推理成本多高？

## Agent 论文

### 任务与环境

- 环境类型：网页、桌面、代码、工具、游戏、社会模拟、科学任务、真实系统。
- 任务是否可重置，是否有隐藏状态，是否允许外部工具。
- 单任务还是长程复合任务，时间跨度多长。
- 成功标准是否客观，是否允许人工介入。

### 状态、动作与观察

- 状态是文本、图像、结构化数据还是混合模态。
- 动作空间是否离散、可组合或通过代码表达。
- 观察是否有噪声、延迟、部分可观测或不可逆操作。

### 规划与推理

- 是否显式规划、树搜索、反应式决策或混合策略。
- 计划如何分解、验证、修订和终止。
- 是否能处理长期依赖、错误恢复和不确定性。

### 记忆

- 记忆写入、检索、更新、遗忘和冲突消解机制。
- 是短期上下文、向量库、图结构、数据库还是参数化记忆。
- 是否评测记忆污染、过时信息和隐私。

### 工具与动作执行

- 工具发现、选择、参数生成、错误处理和安全边界。
- 是否允许重试、回滚、人工确认和权限控制。
- 工具 API 变化后是否稳健。

### 学习与训练

- Prompting、SFT、RL、DPO、自反思、经验回放或无需训练。
- 训练信号来自成功率、过程奖励、人工反馈还是自生成数据。
- 是否存在数据泄漏、奖励作弊和训练-评测重叠。

### 多 Agent

- 角色、通信协议、拓扑、共享记忆和任务分配。
- 通信成本、冲突解决、冗余和失败传播。
- 多 Agent 是否真的优于单 Agent 或增加采样预算。

### 评测

- Benchmark、任务数量、难度、随机种子和重复次数。
- 最强基线是否包含相同模型、同样工具、同样推理预算。
- 是否报告成功率的方差、置信区间和失败分类。
- 是否评测长程、分布外、工具失败和恢复能力。

### 成本与安全

- token、延迟、工具调用次数、货币成本。
- 越权、提示注入、隐私、不可逆动作和沙盒逃逸。
- 安全机制是否被独立评测，而不是只写在 limitations。

## 机器人 / 具身智能论文

### 本体与任务

- 机器人形态、自由度、末端执行器、移动底盘或人形本体。
- 任务数量、任务长度、物体多样性、场景多样性和语言指令复杂度。
- 单任务专用、多任务、跨本体还是通用策略。

### 感知与状态

- RGB、RGB-D、点云、触觉、本体感受、语言和力反馈。
- 观测频率、历史窗口、相机配置和标定要求。
- 是否存在遮挡、动态环境、部分可观测和传感器噪声。

### 动作与控制

- 动作空间：关节位置/速度、末端位姿、EE delta、离散技能或混合动作。
- 控制频率、动作分块、闭环频率和推理延迟。
- 低层控制器是什么，策略是否依赖不可复现的控制栈。

### 策略与模型

- 是模仿学习、RL、VLA、世界模型、扩散策略还是模块化系统。
- 视觉编码器、语言模型、动作头和训练目标。
- 是否使用预训练、冻结模块、LoRA 或端到端训练。
- 参数规模与实时推理硬件。

### 数据

- 真机遥操作、演示、仿真、互联网数据、视频和自动标注。
- 数据量、任务覆盖、操作者数量、采集协议和质量控制。
- 是否报告数据效率、共同训练比例和跨任务迁移。

### 仿真与真机

- 仿真器、资产、随机化和物理保真度。
- 是否做 sim-to-real，使用何种域随机化或真实数据校准。
- 真机实验数量、机器人数量、试验次数和评价者。
- 真机结果是否独立于训练场景。

### 泛化

- 新物体、新位置、新指令、新场景、新任务和新本体。
- 语言组合泛化、视觉分布外和长程组合能力。
- 失败后恢复、重试和人工接管能力。

### 安全与效率

- 碰撞、力限制、紧急停止、工作空间和安全控制器。
- 推理延迟、控制频率、显存、能耗和部署成本。
- 样本效率、训练时长和数据采集成本。

### 结果审计

- 成功率是否给出 trial 数和置信区间。
- 基线是否在同样数据、算力和控制频率下训练。
- 消融是否隔离预训练、数据规模、动作表示和训练算法。
- 视频结果是否和定量结果一致，是否有 cherry-picking 风险。

## 评分建议

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 问题价值 | 局部工程问题 | 明确方向缺口 | 改变常见问题定义 |
| 新颖性 | 已知组合 | 有效新机制 | 新范式且证据扎实 |
| 证据强度 | 单一场景或弱基线 | 多任务且基线合理 | 多环境、多基线、真机/用户验证 |
| 可复现性 | 信息不足 | 有代码和主要设置 | 代码、数据、模型和日志完整 |
| 实用价值 | 场景很窄 | 可迁移部分明确 | 可直接影响系统设计或研究路线 |

不要只给总分。每一维给出证据和扣分原因。
